Privacy Disclosure

Draft for Review • Technical Architecture Transparency

This disclosure outlines exactly what data JakeResume handles, where it is stored, and which external services receive data based on verified source code implementation.

1. Guest Mode (Device-Local Storage)

When using JakeResume without signing in:

  • All resume documents, section ordering, and contact information are saved exclusively in your web browser's local storage (under the key jakeresume:guest:v1).
  • No account is created, and no resume data is transmitted to or stored on our application database.
  • If you clear your browser cookies and site storage, all local guest resumes are deleted.

2. Account Mode (Google Sign-In & Persistence)

If you choose to sign in using Google OAuth:

  • Stored in Database: We store your Google Unique Subject ID (googleId), verified email address (email), account creation timestamp, and your resume profile documents (sections, items, bullets, names, and contact links).
  • Not Stored: We never request, receive, or store Google passwords or access to external Google Drive or Gmail data.
  • Session Security: Sessions are secured via an HS256 signed JSON Web Token stored in an httpOnly, sameSite: lax cookie.

3. Third-Party PDF Compilation Service

When you click Export PDF or Compile PDF:

  • The text content of your resume is compiled into a LaTeX document and sent through our API proxy to a third-party compilation service (by default, latexonline.cc) solely to convert the LaTeX syntax into a binary PDF document.
  • The compilation service processes the document ephemerally and returns the compiled PDF file to your browser.

4. Overleaf Integration (Optional)

When you click Open in Overleaf:

  • Your generated resume LaTeX code is submitted directly to Overleaf (https://www.overleaf.com/docs) via an HTML POST form in your browser. This action occurs only upon direct user request.

5. Analytics & Telemetry

JakeResume contains zero third-party tracking scripts, analytics cookies, advertising SDKs, or telemetry beacons.

6. Data Deletion

Guest Data: Cleared immediately whenever you clear site data in your browser, or click "Leave guest mode" / reset profiles.

Account Resumes: You can delete individual resume profiles inside the workspace at any time; deletion immediately removes the profile record from the database.

Account Record: Please note that currently there is no automated self-service account deletion button inside the UI. To request complete removal of your email and account identity record from the database, please contact the repository administrator.
