### Phase 1 Secret Remediation Steps (For Repository Owner)
If any historical placeholder or test credential needs permanent removal from Git history:
1. Ensure your remote working copies are clean and backed up.
2. Install `git-filter-repo` (`brew install git-filter-repo` or `pip install git-filter-repo`).
3. Run: `git filter-repo --replace-text <(echo "supersecretjakeresumejwtkey2026!==>REDACTED")` or use BFG Repo-Cleaner to scrub specific strings.
4. Rotate any credentials associated with production (e.g. generate a fresh 32+ character `JWT_SECRET` in Vercel project environment variables, and create dedicated Atlas DB credentials).
